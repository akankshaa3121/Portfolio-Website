# Task Management Dashboard

A responsive React Task Management Dashboard developed as part of the MERN Stack Development Internship – Task 2.

## Features
- Task management with Add/Delete
- Search and category filter
- REST API integration using Axios
- Loading, error and empty states
- User Profile
- React Router navigation
- Dark Mode
- Responsive design
- LocalStorage persistence

## Technologies
- React + Vite
- Tailwind CSS
- Axios
- React Router
- DummyJSON API

## Setup

```bash
npm install
npm run dev
```
